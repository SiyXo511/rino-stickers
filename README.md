# 璃乃表情包 · Inosaki Rino Stickers

《公主连结》角色衣之咲璃乃（Inosaki Rino）的非官方同人表情合集，使用 AI 辅助制作。

## 版本

| 版本 | 表情数量 | 静态 | 动态 |
| --- | ---: | ---: | ---: |
| [v1.1](v1.1/) | 新增 8 | 0 张 PNG | 8 张 GIF |
| [v1.0](v1.0/) | 15 | 8 张 PNG | 7 张 GIF |

所有表情均为透明背景。静态图片为 512 × 512，动态图片为 240 × 240，循环播放。

每个版本文件夹保存该次新增的 PNG 或 GIF，当前共 23 款表情：8 张静态、15 张动态。
